# What FragmentedFox changes

Everything is a default, a removal or a name change on top of Mozilla's ESR source. This page is the map; each topic has its own page.

| Page | What it covers |
| --- | --- |
| [defaults](./defaults.md) | Prefs, settings and engine switches that differ from Mozilla: telemetry and background connections, search and DNS, TLS, tracking protection, tabs and memory |
| [removed](./removed.md) | Features, SDKs and code deleted from the Android app (VPN, Adjust, Firebase, summarizer, Pocket, Lens, Labs and so on) |
| [maintenance](./maintenance.md) | Bug fixes and backports, dependency and tooling changes, clean-ups of dead code |
| [branding](./branding.md) | Name, icons, colours, vendor and the text shown on first run |
| [known-gaps](./known-gaps.md) | Open problems, security review notes and things deliberately left as Mozilla ships them |
| [status](./status.md) | Which build contains what, and what is still unbuilt |

Related: [network](./network.md), [telemetry](./telemetry.md), [memory](./memory.md), [licensing](./licensing.md), [signing](./signing.md), [building](./building.md), [upgrading](./upgrading.md).
